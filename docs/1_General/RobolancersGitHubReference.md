# Reference page for the Robolancers Github

### Codespaces

#### Creating a Codespace.

to create a codespce, navigate to the Github repo you want to work on in your browser.
On the code tab, select the code button (in green), then select the codespaces tab.
Select the plus sign to create a new codespace. The codespace will take a few minutes to generate.
